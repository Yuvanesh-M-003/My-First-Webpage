💌 Valentine Web App

This is a simple Valentine web application where users can send messages through a webpage. The submitted messages are stored in a database using a backend server.

🚀 Features

Users can submit Valentine messages

Messages are stored in a database

Simple and responsive web interface

Backend API handles message storage

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: MongoDB

Deployment: Render

⚙️ How It Works

User opens the webpage

User enters a message and submits the form

Frontend sends a request to the backend

Backend stores the message in the database

🎯 Purpose

This project was built to practice full-stack web development including frontend, backend, and database integration.
